If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.

Official name: Knot Your Kind — A Slipknot Experience. Never "A Tribute to Slipknot". Never brand as "Kinda".

Colors hard: Black #000000, White #FFFFFF, Brand red #D2232A, Deep red #8E1D21, Pure red #FF0000. READ MORE hover #A50000, Nav hover #FF3900, Nav active #F00000. Dropdown #1B1B1B, Popup #2A2A2A, Filter chip #333333. Never Gutenberg orange, Blanky #F8AB43, or rainbow fills.

Type: Anybody 700. Uppercase labels and headlines. Line-height ~1 on H1. Arial only for form email fields. Logo, wordmark, and nonagram are image assets only.

Look: late-90s/2000s nu-metal poster, cleaned up. Black canvas, white type, blood-red hits. Sharp rectangles (radius 0), no drop shadow. Section rhythm black → inverted white slab with diagonal cuts → black. Hero may use tribal S / nonagram. Quiet motion: hover-to-red, ~0.3s.
